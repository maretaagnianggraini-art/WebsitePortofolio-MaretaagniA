About

Pendidikan

Saya merupakan siswi dari SMK Negeri 1 Nglegok dengan jurusan Teknik Komputer dan Jaringan (TKJ). Selama menempuh pendidikan di bidang ini, saya mempelajari berbagai dasar dan praktik dalam dunia jaringan komputer, mulai dari instalasi sistem operasi, konfigurasi jaringan, hingga troubleshooting perangkat. Saya juga terbiasa menggunakan berbagai tools seperti Cisco Packet Tracer untuk simulasi jaringan. Melalui pembelajaran ini, saya tidak hanya memahami teori, tetapi juga mengasah keterampilan praktik yang sangat dibutuhkan di dunia kerja, khususnya di bidang IT dan jaringan.

Hobi

Saya memiliki beberapa hobi yang membantu saya mengembangkan kreativitas dan menjaga keseimbangan dalam kehidupan sehari-hari. Saya senang menulis untuk mengekspresikan ide dan pikiran saya, baik dalam bentuk catatan maupun karya sederhana. Selain itu, saya juga menikmati mendengarkan musik karena dapat membantu meningkatkan fokus dan suasana hati. Di waktu luang, saya juga bermain game seperti Block Blast sebagai sarana hiburan sekaligus melatih konsentrasi dan strategi.

Keahlian

Saya memiliki beberapa keahlian di bidang teknologi, khususnya yang berkaitan dengan komputer dan jaringan. Saya mampu melakukan instalasi sistem operasi seperti Debian dan Windows, serta memahami dasar konfigurasi jaringan. Saya juga terbiasa menggunakan Cisco Packet Tracer untuk membuat dan mensimulasikan topologi jaringan. Selain itu, saya memiliki kemampuan dalam menggunakan Figma untuk desain UI sederhana serta membuat desain logo. Saya terus berusaha mengembangkan kemampuan saya, termasuk di bidang network security dan eksplorasi tools seperti Kali Linux dan Metasploit.

Motivasi

Saya percaya bahwa kegagalan bukanlah akhir dari segalanya, melainkan bagian dari proses menuju kesuksesan. Setiap kesalahan yang saya alami menjadi pelajaran berharga untuk menjadi lebih baik ke depannya. Saya selalu berusaha untuk terus belajar, berkembang, dan tidak mudah menyerah dalam menghadapi tantangan. Dengan semangat dan tekad yang kuat, saya yakin dapat mencapai tujuan saya dan memberikan hasil terbaik dalam setiap kesempatan yang ada.
